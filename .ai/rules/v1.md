# V1

## Mobile weather card endpoint: one WeatherKit call, never a 500
GET /api/v1/weather lists the caller's located places (phone app location first, then id, max 25 via GetUserWeatherPlaces) and returns the card for ?location= or the first; a location outside that list is 404, a non-integer 422.
Exactly one GetPlaceWeather call per request. WeatherKit failures (null or exception) give 200 with FormatPlaceWeather::unavailable and a null attribution, never a 500. Apple attribution is returned only when the selected card is available.
GetPlaceWeather caches units-neutral metric data per 0.01-degree cell + timezone (10 min; failure 60 s); units, hour/day staleness and labels are applied after the cache in FormatPlaceWeather.
Apple's attribution endpoint is /attribution/{lang} with NO /api/v1 prefix (the weather endpoint has it). Tests must Http::fake both and Cache::flush().
